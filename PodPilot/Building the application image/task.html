Description

Now that your local Kubernetes environment is ready, it's time to prepare your application for deployment! We'll be working with a simple Task Manager application built with Django that you can find in the task_manager directory. You don't need to know Python or Django to work on this project.

Navigate to the task_manager directory and build the Docker image from the provided Dockerfile. Tag the image task-manager:latest. Before deploying to Kubernetes, it's always a good idea to run the image locally to make sure it starts correctly. You can run the task-manager container with the following command:

docker run -d -p 8000:8000 --name task-manager-local task-manager:latest

Verify that your application is running and that its health endpoint is reachable. The application already includes a /health endpoint that returns a status, confirming the application is alive.

curl http://localhost:8000/health

# {"status": "healthy"
Invoke-RestMethod -Uri "http://localhost:8000/health" -Method GET

# status
# ------
# healthy

Finally, you need to make this image accessible to your local Kubernetes cluster.

If you're using minikube, you can load the image to the cluster with the following command:

minikube image load task-manager:latest

You can verify the image was loaded with:

minikube image list

If you're running a kind cluster, you can do it with the following command:

kind load docker-image task-manager:latest --name kind

The --name argument is the name of your kind cluster. You can verify this name with:

kind get clusters

For Kubernetes clusters in Docker Desktop, the image is already available to your cluster, so you do not need to load it.

Objectives

This is what you need to do here:

  • Build and tag the application task-manager:latest.

  • Run the task-manager:latest image locally, publishing port 8000.

  • Verify that the application's health endpoint is reachable.

  • Load the image to your Kubernetes cluster.
